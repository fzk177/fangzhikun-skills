# 环境配置

本机 `runtime.json` 的 `weaver` 段是唯一环境来源。结构示例见 [配置示例](configuration-example.md)。

| 用户环境 | 物理环境键 | 会话与凭证 |
|---|---|---|
| dev / 开发 | test | 与 pre 共用测试环境条目 |
| pre / 预发 / 测试 | test | 与 dev 共用测试环境条目 |
| prod / 生产 / 正式 | prod | 独立生产条目 |

脚本只接受标准英文环境参数；AI 根据上表转成英文，不改变用户选定环境。两个物理环境的地址必须不同。真实配置中保留完整协议、域名和端口；不按二级域名推断环境，不读取官方 CLI 的全局 profile。

测试和生产不能隐式切换。一次 `run` 固定环境、CLI 版本及请求代码摘要；写请求批准后再次核对，变化则该批准失效。任务中途切换环境必须启动新的明确环境操作。

账号可以不同；即使用户明确表示账号相同，也分别录入两个钥匙串条目，不自动复制密码或会话。首次录入后由脚本在内存中使用凭证，AI 不读取钥匙串内容。
