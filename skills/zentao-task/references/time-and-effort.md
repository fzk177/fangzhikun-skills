# 时间与工时

仅在阶段二或四读取本文件。

1. 默认本次消耗等于禅道当前剩余工时。代码确认当下为实际完成时间，精确到秒；实际开始时间 = 实际完成时间 - 本次消耗工时。
2. 工时允许小数，按实际秒数换算并向前推算；跨日期保留正确日期，使用项目上下文所在本地时区。例如剩余 `2h`、确认时间 `2026-08-13 19:04:37`，实际开始为 `2026-08-13 17:04:37`。
3. 阶段二创建 `coding` 记录时，可用当时当前时间减去剩余工时生成临时时间；阶段四代码确认时必须按确认当下重新计算并覆盖，后续只使用最终持久化时间。
4. 任务已经为 `doing` 且禅道存在实际开始时间时，以只读获取的远端时间为准，不自动覆盖；若与本地推算冲突，在代码确认预览中展示并等待确认。
5. 用户明确指定实际开始、实际完成或要求真实计时时，用户值优先；完成早于开始、剩余工时异常或无法唯一计算时停止询问，不得猜测。
