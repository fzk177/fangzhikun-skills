# 服务器别名注册表

真实服务器登记只保存在本机：

```text
~/.config/fangzhikun-skills/profiles/server-connect.md
```

每次连接前必须完整读取该文件，将用户输入解析为唯一且状态为“已确认”的 SSH 别名。文件缺失、别名未登记、状态未确认或同一名称匹配多台服务器时停止，不根据历史对话、IP、环境名或表格顺序猜测。

本机注册表只记录标准别名、可识别名称、SSH 别名、环境、用途和确认状态。真实 HostName、User、IdentityFile、ProxyCommand 等连接细节继续由 `~/.ssh/config` 管理，避免在 Skill 或公开仓库中重复保存基础设施信息。

## 扩展规则

登记新服务器时，同时完成以下事项：

1. 使用不随 IP 变化的标准别名，格式优先为 `<业务>-<环境>`。
2. 在本机注册表登记可识别名称、唯一 SSH 别名、环境、用途和确认状态。
3. 在 `~/.ssh/config` 中新增独立 `Host` 块，不复用其他服务器的账号、主机或密钥假设。
4. 由用户在自己的终端完成密码或密钥初始化；不要把密码、私钥内容写入 Skill、项目或对话。
5. 使用 `BatchMode` 和短连接超时验证。只有验证成功后才把状态标为“已确认”。
6. 同一自然语言别名可能对应多台服务器时，必须让用户明确目标。
