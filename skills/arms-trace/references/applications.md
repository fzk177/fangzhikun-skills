## 维护规则

- 清单只保存非秘密映射；严禁 AccessKey、STS Token、Cookie、密码、私钥、完整请求 Header 和未脱敏报文。
- CLI 配置名称已观察不等于对应账号已确认或查询权限有效；运行查询前固定本次身份。
- 一个 Trace 的 Span 查询成功只确认该样本及实际返回服务，不扩展为其他服务、环境、列表查询、完整参数采集均已验证。
- 每条验证记录分别说明 `GetTrace`、`SearchTraces`、入参和出参的状态，附核验日期及证据位置。
- 日常只按问题范围查询；用户本次明确要求全部时，在明确时间与身份后逐服务限量读取，不做无界扫描。
- 本机验证资料另存 `~/.config/fangzhikun-skills/arms-trace/trace-validation.md`。公共 Skill 更新不覆盖这两个本机文件。
